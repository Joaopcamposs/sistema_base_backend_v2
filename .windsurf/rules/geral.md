# Código
- Use type hints de forma consistente.
- Tenha preferencia por legibilidade em vez de otimização prematura.
- Escreva código modular, utilizando arquivos separados para entidades, carregamento de dados (repositório).
- Crie funções curtas e com propósito claro quando necessário.
- Siga o guia de estilo PEP8 para código Python (versão 3.11).
- Use entidades e funções puras sempre que possível.
- Use de base so padrões de arquitetura solid, repository, ddd e event-driven (baseado no cosmic python).
- Faça código limpo, com docstrings e em casos complexos, crie readmes explicando o contexto.
- Sempre faça testes unitários e de integração para novas implementações ou mudanças.
